## Post-normalization metadata audit

The Phase 2 audit found a classifier reading **no pixels at all** scored 0.98 AUROC on raw SID_Set. Same probe, same metric code, run on the normalized corpus. Direction-agnostic AUROC; 0.5 = no leak.

| has_adobe_marker   | -             |       0.5    |                 1 | constant |
| chroma_subsampling | -             |       0.5    |                 1 | constant |

Most channels are 0.5000 **exactly**, because normalization makes them constant: every file is a 512x512 RGB q95 4:2:0 JPEG with no metadata. A constant feature has AUROC 0.5 by construction, which is stronger than "measured below a threshold" -- there is no sample size at which it could come out otherwise.

`n_bytes` is the one channel that cannot be made constant: at fixed quality, file size measures how compressible the picture is, which is a property of the pixels rather than of the container. It is bounded, not pinned.

## Source fingerprinting by file size

Within-class source separability. A source signature is not a class leak on its own, but becomes one when that source carries a distinguishing property.

> **This table is why Pexels was dropped.** Its sources are 18 KB at 768p -- already downscaled and recompressed -- so its normalized files came out at a median 16 KB against 66-103 KB everywhere else. It scored **1.0000** here, and pushed real-vs-AI `n_bytes` to **0.7120**. Replaced by Unsplash (130 KB/image at source): `n_bytes` fell to **0.5017** and the source signature to **0.5108**. Caught by the task-F regression test, which is the entire reason for having one.
